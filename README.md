# 飞书仪表盘插件 v0.1.10 · GitHub 上传精简版

此目录只保留飞书使用需要的源码、配置、构建脚本及 dist。已移除测试、测试数据、虚构示例数据、截图、视频、缓存和 node_modules。

上传方式：将本目录里面的全部文件和文件夹上传到 GitHub 仓库根目录，务必包含 src、scripts、dist 和 package.json。不要上传外层目录或 ZIP 本身。更新 GitHub 后，到飞书开发者中心发布更新，并在插件配置中确认 v0.1.10。

多字段各自作为一根堆积柱，逐字段忽略空白值，空白不计入数量、图例或百分比分母。保留条件筛选、点击色块看明细、隐藏明细字段、按参考视图排列及透明背景透字修复。

独立网页不再显示虚构示例数据，请从飞书仪表盘中打开。需要大面积查看明细时，使用飞书组件自身的全屏入口。

仅在本地修改源码时需要 Node.js 22.12+，运行 npm ci 后执行 npm run build。重新上传时不要包含 npm ci 生成的 node_modules，也不要遗漏重新构建的 dist。
