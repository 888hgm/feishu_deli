# 飞书多维表格多字段堆积柱状图

版本：0.1.6。

选中多个文本状态字段，每个字段显示一根柱，分别统计其中“完成”“未完成”等文字的记录数量。可以选三个、四个或更多字段，不再把所有字段提交到同一个 Dashboard 分组查询中。

默认图表为百分比堆积，柱高归一到 100%，柱内标签显示实际数量。例如完成 8 条、未完成 12 条时，分段高度为 40% 和 60%，标签显示 8 和 12。也可切换普通堆积、分组柱状图，或将标签改为百分比。

## 条件筛选

点击“数据范围”右侧的“筛选”，在弹窗中选择字段、运算符和筛选值。

- 支持等于、不等于、包含、不包含、为空、不为空。
- 支持添加、删除和清空条件，以及满足全部条件或任一条件。
- 点击“应用筛选”后，先筛选记录，再对每个横轴字段独立计数。
- 筛选条件随“保存配置”写入飞书，重新打开时恢复。
- “为空”和“不为空”不需要填写筛选值。

例如设置“产品公司 等于 某公司”，所有柱子都只统计该公司的记录，而不是筛选横轴字段名称。

## 统计范围与刷新

多字段模式使用 Base SDK 的 `getRecordsByPage({ pageSize: 200, stringValue: true })` 分页读取当前账号可读的全表记录，不受单次 Dashboard 分组数量限制。每页读取后立即累计选中字段，继续读取后续页，不把前 200 条当成全部数据。数据读取失败或分页异常时报告错误，不展示截断的结果。

**多字段模式不自动跟随仪表盘外层的全局筛选，也不按源表当前视图过滤。请在插件自己的筛选弹窗设置所需条件。使用者需要拥有读取源表记录的权限。**

监听源表记录新增、删除和修改事件刷新数据；提供配置页“刷新数据”按钮及页面可见时的 30 秒补充刷新。记录读取和事件能力在真实飞书环境中仍需验证，尤其是仅有仪表盘阅读权限、没有源表读取权限，以及自动化截图的场景。

每条筛选后的记录会在每个选中字段中各统计一次，因此“字段统计次数”不是去重记录数。状态文字按完整文本分类，“完成”和“未完成”分开计数，空文本归入“未填写”。字符串按首尾去空格后比较。

## 上传 GitHub 与飞书

详细点击步骤见 [UPLOAD_TO_GITHUB.md](./UPLOAD_TO_GITHUB.md)。

1. 解压完整源码包，将里面的文件和文件夹上传到公开 GitHub 仓库的默认分支。
2. 仓库首页应直接看到 `package.json`、`src`、`dist`、`scripts` 和 `vite.config.ts`。不要只上传 ZIP，也不要套额外目录。
3. 飞书开发者中心选择“插件 → 仪表盘插件”，在“插件代码 Github 地址”填写仓库主页地址。
4. 按页面要求填写基础信息，发布或更新版本。平台审核结果以实际操作为准。
5. 在组件配置中确认版本号为 `v0.1.6`，选择数据表、横轴字段和筛选条件，再保存配置。

源码包包含预构建的 `dist`，`package.json` 设置 `output: dist`。Vite 使用 `base: './'` 生成相对资源路径，构建后自动检查入口和资源文件。

“插件代码 Github 地址”填写源码仓库主页；若使用仪表盘内“添加自定义插件 → 服务地址”的入口，需要先部署 HTTPS 网站，再填写网站运行地址。

## 本地运行

构建需要 Node.js 22.12 或更高版本，建议 Node.js 24 LTS。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

PowerShell 若拦截 `npm.ps1`，可将命令中的 `npm` 换成 `npm.cmd`。独立网页使用虚构示例数据；飞书 iframe 中连接宿主。修改源码后应重新构建，并同时更新仓库中的 `dist`。

## 其他模式与边界

- 保留单字段分类模式，使用 Dashboard 服务端聚合，支持计数和数值统计；该模式的旧关键词筛选针对分类名称，不使用新的记录条件弹窗。
- 多数据表的字段名称及选择顺序必须一致；筛选字段在各表中也需要同名。
- 多选字段使用 SDK 返回的展示文字整体分类，不拆分选项。
- 复制到另一份 Base 后若字段 ID 变化，应重新选择源表及字段；暂未实现所有自定义字段引用的复制映射。
- 支持标题、配色、渐变、标签、图例、坐标轴、网格线、字段排序、横向显示和图表画布 PNG 导出。

## 验证

31 项自动化测试覆盖原有模型、交叉表解析、四字段独立统计、241 条记录分页、重复记录去重、分页失败、六种筛选运算符、全部／任一条件、空值以及跨表筛选字段映射。

浏览器模拟验证覆盖创建、配置、保存、展示和全屏状态，四个字段同时出图、筛选弹窗、筛选后重新计数、保存恢复以及记录修改刷新。模拟宿主会拒绝超过两个分组的查询，以检查新实现不再依赖该查询路径。模拟验证不能替代真实飞书联调。

参考：[官方 Dashboard 开发模板](https://github.com/Lark-Base-Team/dashboard-html-template)、[Table SDK 分页接口文档](https://lark-base-team.github.io/js-sdk-docs/zh/api/table.html)。仓库无需填写飞书 App Secret、GitHub Token 或云服务密钥，也不会主动将源表记录发送到外部服务。
