# 飞书仪表盘插件 v0.1.11 · GitHub 上传精简版

此目录只保留飞书使用需要的源码、配置、构建脚本及 dist。已移除测试、测试数据、虚构示例数据、截图、视频、缓存和 node_modules。

上传方式：将本目录里面的全部文件和文件夹上传到 GitHub 仓库根目录，务必包含 src、scripts、dist 和 package.json。不要上传外层目录或 ZIP 本身。更新 GitHub 后，到飞书开发者中心发布更新，并在插件配置中确认 v0.1.11。

多字段各自作为一根堆积柱，逐字段忽略空白值，空白不计入数量、图例或百分比分母。保留条件筛选、点击色块看明细、隐藏明细字段、按参考视图排列及透明背景透字修复。

## 按 SKU 数量统计

1. 在基础配置中找到“纵轴（统计方式）”，选择“SKU数量求和”。原来的“统计记录总数”仍可随时切换。
2. 在下方“SKU数量字段”中选择源表的“SKU数量”数字字段。名称恰为“SKU数量”时自动选中；没有匹配项时请手动选择。多数据源需要分别选择各表的 SKU 数量字段。
3. 点击“保存配置”。每根柱仍对应一个状态字段，完成／未完成分别累加对应记录的 SKU 数量。

例如同一阶段两条完成记录的 SKU 数量为 4 和 3，一条未完成记录的 SKU 数量为 2，则完成显示 7、未完成显示 2，百分比按 7/9 与 2/9 计算。

空白状态继续忽略，只排除该字段本次统计，不删除整行。SKU 数量空值按 0 处理；非数字、负数或合计溢出时提示错误。支持数值、数字字符串及有效千分位数字。点击色块后的明细会分别显示“记录条数”和“SKU合计”，搜索后显示搜索结果的 SKU 合计。

“字段SKU统计合计”是所有横轴字段统计值之和；同一条记录的 SKU 可能分别参与多个阶段，不能将它作为源表去重 SKU 总量。记录统计范围仍是当前账号可读记录加插件自身筛选条件，不自动跟随外层仪表盘的全局筛选。
